# Mandatory Part: `src/models.py`

## 1. Overview & Architectural Role

[`src/models.py`](../src/models.py) defines the **Pydantic v2 data interchange schemas** specified in Chapter VI.4 & VI.5 of the subject. These models define the exact data contract passed between the pipeline stages (ingestion, retrieval, generation) and written to disk for evaluation by the official `moulinette`.

All models use:
```python
model_config = ConfigDict(frozen=True, extra="ignore")
```
- `frozen=True`: Guarantees immutability across pipeline stages.
- `extra="ignore"`: Silently ignores unknown fields during deserialization, ensuring resilience when reading datasets with extra metadata (like `"difficulty"` or `"is_valid"`).

## 2. Helper: `normalize_file_path`

### Purpose
The subject specifies:
> *"file_path must match the corpus path exactly (e.g. data/raw/vllm-0.10.1/docs/features/lora.md). The grader compares paths verbatim, so a path with a different prefix never matches."*

### Implementation Details
```python
def normalize_file_path(path: Union[str, Path]) -> str:
```
- Converts Windows backslashes (`\`) to forward slashes (`/`).
- If an absolute path is passed (e.g. `/home/user/project/data/raw/vllm-0.10.1/...`), it slices from `data/raw/`.
- Strips leading redundant `./` and `/`.
- Uses `posixpath.normpath` to eliminate internal redundant separators (`//`) or parent navigations.
- Rejects empty paths or paths resolving to `"."`.

## 3. Data Models Specification

### 3.1 `MinimalSource`
Represents a single retrieved text span from the corpus.
- `file_path: str`: Normalized relative path. Automatically cleaned by `@field_validator("file_path", mode="before")`.
- `first_character_index: int`: 0-based character start position (`ge=0`).
- `last_character_index: int`: 0-based character end position (`gt=0`).
- Validation: `@model_validator(mode="after")` enforces `last_character_index > first_character_index`.
- Property: `span_length -> int` (`last_character_index - first_character_index`).

### 3.2 `UnansweredQuestion`
Represents an input question awaiting retrieval.
- `question_id: str`: Unique identifier (auto-generates UUID4 string if omitted).
- `question: str`: Non-empty text query. Strips whitespace and raises `ValueError` if blank.

### 3.3 `AnsweredQuestion` (Inherits from `UnansweredQuestion`)
Represents a ground-truth item in `data/datasets/AnsweredQuestions/`.
- `sources: List[MinimalSource]`: Ground-truth source locations.
- `answer: str`: Reference answer text.

### 3.4 `RagDataset`
Represents an entire question file (`dataset_docs_public.json` or `dataset_code_public.json`).
- `rag_questions: List[Union[AnsweredQuestion, UnansweredQuestion]]`: List of question objects.

### 3.5 `MinimalSearchResults`
Output of searching a single query.
- `question_id: str`: Question identifier.
- `question: str`: Question text.
- `retrieved_sources: List[MinimalSource]`: Up to $k$ retrieved candidate sources.

### 3.6 `MinimalAnswer` (Inherits from `MinimalSearchResults`)
Output of answering a single query.
- Inherits `question_id`, `question`, and `retrieved_sources`.
- `answer: str`: Natural-language answer generated by `Qwen/Qwen3-0.6B`.

### 3.7 `StudentSearchResults` (Official Moulinette Output)
Output generated by `search_dataset`:
- `search_results: List[MinimalSearchResults]`: List of search results for all questions.
- `k: int`: Cutoff parameter ($k \ge 1$).

### 3.8 `StudentSearchResultsAndAnswer` (Official Moulinette Output)
Output generated by `answer_dataset`:
- `search_results: List[MinimalAnswer]`: List of answers and sources for all questions.
- `k: int`: Cutoff parameter ($k \ge 1$).
